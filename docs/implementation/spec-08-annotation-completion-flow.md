# 批注完成反馈与统一生成

2026-11-08：用户确认精简方案，解决填写批注后缺少完成反馈，以及已有补充参考图导致生成按钮禁用、解决入口不清楚的问题。

## 行为

- 当前批注提供“完成”：校验本条说明、结束编辑并收起浮框，在对应条目旁和画布工具区显示“批注 N 已录入”。只有工具区播报完成反馈，避免重复朗读。
- 浮框和列表仍编辑同一份草稿。完成反馈为临时界面状态，不增加持久化的完成字段；有效文字未点击完成也可以统一提交。
- 输入时的反馈为“批注内容已更新”，不把同步更新误报为浏览器存储成功。原有自动保存、按账号/创作/基准版本恢复与保存失败提醒保留。
- 批注输入框内 Enter、Shift+Enter 换行；Ctrl/Cmd+Enter 只完成本条，阻止冒泡；中文输入法组合期间不触发完成。整体要求输入框中 Shift+Enter 也保留换行。
- 编辑区底部保留唯一生成按钮。已有成功基准时显示“生成新版本”，旁边显示基准版本和批注数量；桌面独立于左栏滚动，窄屏固定底部并预留内容空间。
- 禁用时显示具体原因；缺少批注说明提供“去填写”，定位并聚焦对应输入。
- 批注与补充参考图冲突时保留原输入，提供“移除参考图”。只清除补充参考图，保留原始基准、批注和整体要求；解除后即时重算可提交状态并移除冲突提示。
- 有批注时暂停添加补充参考图，文件、链接、拖放、粘贴与异步转换完成入口遵循同一规则。

## 兼容边界

沿用 overlay-v1 的两张图片总预算、原图及辅助图角色、私有 COS、请求冻结和恢复契约。本次不改变模型配置、请求协议、数据库迁移、浏览器 workspace schema 或已保存的批注格式。

## 验证

- 真实组件回归覆盖单条完成、空说明、两处同步、焦点、IME/快捷键、多条批注中第一条的就近反馈，以及未点完成的最后文字进入生成请求。
- 整页回归覆盖四条批注加参考图的冲突解除、各参考图入口、刷新恢复和浏览器保存失败保留。
- 浏览器使用实际编辑组件、合成图片与本机模拟接口；装饰背景替换为空组件。图片只在内存中生成和响应，未调用真实模型或写云存储。浏览器布局检查与真实模型编辑效果分别验收。
- 发布和人工验收由实际 PR、CI 与后续上线记录确认，本文件不代表已部署。
